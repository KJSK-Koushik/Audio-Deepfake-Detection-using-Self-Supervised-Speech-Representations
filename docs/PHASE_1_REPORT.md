# Phase 1 Dataset and Metadata Report

## Dataset Decision

The primary dataset is ASVspoof 2019 Logical Access (LA). It contains genuine human speech and spoofed speech generated by text-to-speech and voice-conversion systems. Official train, development, and evaluation partitions are preserved; no random resplitting is performed.

The dataset is available under the Open Data Commons Attribution License (ODC-By 1.0).

The official Edinburgh host was measured at approximately 93 KB/s during Phase 1. The pinned Parquet mirror is used for practical audio transfer, while official protocol content remains the source of labels and split definitions.

Train and development audio are the immediate inputs for Phase 2 and can be downloaded independently with the resumable mirror script. The 4.38 GB evaluation container is deliberately deferred until full model evaluation; this saves local storage and download time without changing its already generated metadata or official labels.

## Validation Performed

- Exact official row and label counts
- Five-column protocol schema
- Allowed labels: `bonafide` and `spoof`
- Fixed label IDs: bonafide `0`, spoof `1`
- Attack/label consistency
- No duplicate utterances inside a split
- No utterance leakage across splits
- No speaker leakage across splits
- Protocol source checksum and pinned revision
- Audio mirror sizes and hashes encoded in resumable download tooling
- Independent train, development, evaluation, or all-split downloads

No synthetic labels are used. Future audio augmentations will inherit the original ground-truth label and will never be allowed to cross the official split boundaries.

## Phase 2 Input

Phase 2 will read the downloaded Parquet audio, validate decoding/sample rates/channels/durations, and implement deterministic mono 16 kHz loading with crop/pad behavior. It will not change labels or split membership.

Phase 2 has not started. Work remains behind the required approval gate.
